站点框架设计笔记

2026-10-28 站点框架 Markdown 1,024 阅读

本站以「简洁、长期、可维护」为目标，把内容与展示彻底分离：内容存于数据库，服务端只输出 JSON，浏览器负责渲染。

核心原则

  1. 内容与站点配置只放在私有目录，不直接暴露给浏览器；
  2. 服务端读取私有数据并输出 JSON，浏览器 fetch 后渲染；
  3. 访问统计保持最小闭环。
精致的界面，来自克制的设计：统一的间距、一致的圆角、单一的主色强调。

一段示例代码

// 站内路径统一走 unhalt_path()
echo unhalt_path('/assets/css/site.css');

更多约定见目录结构与代码约定。

用户反馈 Safari 掉登录态而 Chrome 正常，这是典型的 Set-Cookie 属性差异问题。初步假设 SameSite=None 缺 Secure 会被 Safari 丢弃，或被 ITP 拦截。

大概率是 SameSite / Secure 属性在 Safari 上的差异导致的。

建议修改

res.cookie('sid', token, {
  httpOnly: true,
  secure: true,
  sameSite: 'lax'
});

把 sameSite 从 None 改为 Lax 通常即可解决。
